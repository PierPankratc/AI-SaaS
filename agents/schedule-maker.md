# Scheduler Agent

## Роль
Генерирует расписание, удовлетворяющее ограничениям.

## Skills
- generate_schedule: основной алгоритм (жадный + локальный поиск)

## Жёсткие ограничения (hard constraints)
- Преподаватель не ведёт 2 пары одновременно
- Аудитория не занята дважды
- Группа не имеет 2 пар одновременно

## Выход
{ "schedule": [ { "group": "...", "subject": "...", "teacher": "...", "room": "...", "slot": "Mon-1" } ] }
